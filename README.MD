# 🧪 Qwen Coder Web Sandbox

A test sandbox for the **Qwen Coder web agent**. This repository collects prompts, tasks, and outputs generated directly via the official web interface (no API required).

## 🎯 Goal
To evaluate how the Qwen Coder web agent handles various coding tasks, from writing and refactoring code to debugging.

## 🚀 How to Use
1. Open the Qwen Coder web interface.
2. Copy a task or prompt.
3. Send it to the agent.
4. Save the generated result in this repo.

## ⚠️ Disclaimer
This is an experimental sandbox. Results may vary depending on the current model version and web chat context.
